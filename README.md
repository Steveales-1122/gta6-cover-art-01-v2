Vice City Sunset Studio — a GTA 6-style cover art maker. Drop in your own photo (it never leaves your machine), pick a multi-panel poster layout, paint it with a Vice City sunset or neon grade, set bold caption lettering, and export a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080.

Five one-click looks (Sunset Heist, Boulevard Queen, Neon Nights, Vice Nights, Ocean Drive), five multi-panel layouts, six colour grades, five lettering styles, eight poster effects (sun disc, palm silhouettes, halftone, grain, vignette, scanlines, light leak, duotone), and four procedural sample scenes painted in code — so the studio works with no photo at all.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — everything runs offline from static files under app/.
